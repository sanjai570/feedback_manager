# Event-Based Feedback Management System

A full-featured Django application for managing event-based feedback with Supabase PostgreSQL backend.

## Features
- Student registration and authentication with password reset
- Event management (CRUD operations)
- Feedback submission and collection
- Admin dashboard with analytics
- Department management (CS, IT, ECE, ME, CE, EE, AIML, AIDS)
- Supabase PostgreSQL database integration
- Responsive UI with modern styling

## Tech Stack
- Django 4.2.7
- PostgreSQL (via Supabase)
- Bootstrap & Custom CSS
- Chart.js for analytics
